Use the TypeScript SDK — five lines.

Quickstart (SDK)

import { AgentFence } from 'agentfence-sdk';

const fence = new AgentFence({
  network: 'testnet',
  contractAccount: 'agentfence-contract-evm-0b497ae1.testnet',
  agentAccount: 'agentfence-agent-9a9635f2.testnet',
  agentKeyFile: process.env.AGENT_FCK_KEY_FILE!,
});

const { address } = await fence.deriveAddress();
const result = await fence.pay({ to: '0x1111111111111111111111111111111111111111', amountWei: 1_000_000_000_000_000n });
console.log(result.decision, result.reason ?? '');

Install from this repo: npm install ./sdk (not published to npm).

Honest limitations

  • Spend is reserved when the signature is requested, not when the transaction is mined; a failed broadcast does not refund it.
  • Testnet only. ETH on Sepolia only.
  • No TEE — the MPC is the trust root.
  • An allowlisted destination is trusted; the fence constrains the agent, not the supplier.
  • The owner key is a single key (no multisig).
  • The injection demo uses --force-tool-call to simulate a compromised model unless run with a real LLM (agent/src/agent.ts).
  • The derived EVM address changes if the contract is redeployed to a new account.
